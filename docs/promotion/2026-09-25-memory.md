# Frozen candidate native memory gate

Status: **HOLD — sampled memory gate passed; overall promotion incomplete.**

The [validation-only image build](https://github.com/starknet-innovation/qsb-solver/actions/runs/36121457290)
adds CUDA 12.8 Compute Sanitizer to the exact candidate-20260925-2 filesystem.
It does not recompile either solver. GitHub attestation binds the validation image
to source `70d6f47bb89ca82eb4e01ef3ad239f52283ab011`; installed binary hashes match
the frozen candidate. Exact image, runner, binary and result identities are in the
[machine-readable receipt](2026-09-25-memory.json).

One secure RTX 4090 ran seven bounded cases under memcheck. Each produced an
explicit zero-error summary, expected solver exit and intended execution markers:

- Exact pinning executable: historical one-position hit replay matched its record.
- Exact subset executable: 257 ranks across a block boundary completed.
- Source-bound device capacity diagnostic: 64 retained hits completed; counts 65
  and 1025 reached the device/canary checks and failed closed before publication.
- Forced and actual-detector exceptional diagnostics: seven resolver records each
  completed with the real host resolver. Scalars are injected public test data.

The reviewer identified a harness flaw before execution: unrelated early exit 2
could have passed an overflow case. The corrected harness requires device count,
canary and exact overflow-error evidence, plus resolver markers and completion.
It rejects sanitizer tool errors, missing summaries and nonzero error counts.

The first native attempt was rejected because the harness inspected stderr only
and did not retain failure diagnostics. No gate is credited to that attempt. The
corrected runner inspects both streams and preserves them; the successful run
shows sanitizer summaries on stdout. Its downloaded result matched the SHA256
printed by the worker. All seven cases were rechecked locally.

Both attempt pods were deleted; a fresh provider list showed zero pods before
terminating their deletion watchdogs. Price was announced as $0.74/GPU-hour plus
storage. No production endpoint, app enrollment or fixture spend occurred.

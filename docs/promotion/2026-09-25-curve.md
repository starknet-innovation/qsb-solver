# Native curve implementation audit

**Scoped audit passed. Overall candidate remains HOLD.**

[Native Linux build 36117893998](https://github.com/starknet-innovation/qsb-solver/actions/runs/36117893998)
compiled the candidate and its point diagnostic from the identical source inventory
and CUDA flags in `worker/optimized/source-lock.json`. Every source hash was checked
before diagnostic compilation. The vector generator, harness and bootstrap were
committed and pushed before GPU execution. The solver and its released image were
not modified.

The audit exercised the actual fixed-base point chain and table construction on
one RTX 4090, checking results against OpenSSL `EC_POINT_mul`. There were:

- 5,628 deterministic scalars, including zero, curve-order boundaries, both sides
  of every bit boundary, and 4,096 SHA256-derived random scalars.
- Two independently generated table bases: 11,256 point comparisons total.
- Four infinity cases, checked as infinity rather than ordinary affine points.
- 504 sampled table checks and zero mismatches.

The diagnostic returned zero and the separate receipt checker required the exact
planned case totals, zero errors, expected table-check count and infinity coverage.
Artifact/receipt hashes were checked before execution; the vectors were independently
regenerated locally. [Receipt and public transcript](2026-09-25-curve.json) include
source inventory, flags, compiler, executable/vector hashes and scope.

The single test pod was deleted immediately after collecting the terminal result;
a fresh provider list showed zero pods. Its 29-minute watchdog was terminated only
after cleanup. The announced rate was $0.74/hour plus storage. Historical proof
endpoints and spent fixtures were untouched.

This is a diagnostic executable compiled from the locked implementation, **not the
shipped solver executable**. Sampled point checks do not establish all scalar or
field behavior, final transaction hashing, exception handoff, complete rank coverage,
or a fresh full-predicate withdrawal. Exact-build replays and matched performance
are documented separately in [the benchmark report](2026-09-25-benchmark.md).
Independent final review and fresh final-image end-to-end evidence remain required
before a normal optimized release or app enrollment.
